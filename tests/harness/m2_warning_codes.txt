# M2 WARNING-tier diagnostic gate codes (PRD section 20.3 M2 row: WARNING
# >= 95%, (code,file) Jaccard per section 19.1): the code set for the
# WARNING-severity tier run of the M2 gate (#479). The WARNING tier runs
# one harness invocation over the dedicated `tests/corpus/m2-warning`
# corpus package (`--severity-filter WARNING` plus this `--codes-file`);
# the ERROR tier keeps the m1-semantic corpus and `m1_codes.txt`. One code
# per line, # comments: same format as m1_codes.txt.
#
# Inclusion rule (mechanical, re-derivable): take every code carrying
# `type: DiagnosticType.STATIC_WARNING` in the SDK main unified registry
# (.third/dart-sdk pkg/analyzer/lib/src/diagnostic/diagnostic.g.dart,
# each `name:` literal paired with the following `type:` line) -- the
# severity family `dart analyze --format=machine` reports as WARNING;
# 190 unique names at freeze time -- and intersect it with the per-bucket
# freeze below (PRD section 20.3 M2 feature areas). The pin test
# m2_warning_codes_file_matches_derivation (tests/harness/src/main.rs)
# derives the family live and asserts set equality against this file, so
# a registry drift (a name re-typed or removed) forces a conscious
# re-freeze.
#
# Included buckets (43 codes):
#  (a) M1 frozen-set continuation (4): the m1_codes.txt entries whose
#      registry severity is WARNING (invalid_null_aware_operator,
#      undefined_hidden_name, undefined_referenced_parameter,
#      undefined_shown_name). Mechanical: m1_codes.txt INTERSECT family.
#      Load-bearing: the tier split must not silently unscore M1 rows on
#      the still-scored m2-warning corpus.
#  (b) flow analysis & null-safety soundness (18): dead_code,
#      dead_code_catch_following_catch, dead_code_on_catch_subtype,
#      dead_null_aware_expression, cast_from_null_always_fails,
#      cast_from_nullable_always_fails, null_check_always_fails,
#      null_argument_to_non_null_type, receiver_of_type_never,
#      type_check_with_null, nullable_type_in_catch_clause,
#      unnecessary_cast, unnecessary_nan_comparison,
#      unnecessary_non_null_assertion, unnecessary_null_comparison,
#      unnecessary_question_mark, unnecessary_type_check,
#      body_might_complete_normally_nullable.
#  (c) patterns / records / switch exhaustiveness & reachability (9):
#      constant_pattern_never_matches_value_type,
#      pattern_never_matches_value_type, missing_enum_constant_in_switch,
#      unreachable_switch_case, unreachable_switch_default,
#      unnecessary_null_assert_pattern, unnecessary_null_check_pattern,
#      unnecessary_cast_pattern, unnecessary_wildcard_pattern.
#  (d) class modifiers / sealed (2): mixin_on_sealed_class,
#      subtype_of_sealed_class.
#  (e) const & literal semantics (3): non_const_call_to_literal_constructor,
#      equal_elements_in_set, equal_keys_in_map.
#  (f) import/export combinator duplicates (4): duplicate_import,
#      duplicate_export, duplicate_hidden_name, duplicate_shown_name.
#  (g) override & interface-member semantics (3):
#      override_on_non_overriding_member, non_nullable_equals_parameter,
#      unnecessary_no_such_method.
#
# Exclusions (the other 147 family members; a member is excluded iff it
# is in no bucket above). Excluded families, each mechanically checkable
# by name, with dartq-M2 rationale -- an excluded code's inclusion would
# only add permanent oracle-only denominator rows:
#  - usage analysis `unused_*` (11 names, e.g. unused_import,
#    unused_local_variable, unused_element, unused_field): index/impact-
#    backed usage detection is M3 territory; note these ARE WARNING-
#    severity in the registry, so excluding them is load-bearing for the
#    95% threshold.
#  - deprecation machinery `deprecated_*` (12): deprecation enforcement
#    is not an M2 feature.
#  - opt-in strict analysis (8): strict_raw_type plus the seven
#    inference_failure_on_* codes fire only with analysis-options
#    strict-raw-types / strict-inference enabled (default off); M2
#    options work covers merge mechanics, not these checks.
#  - SDK-feature-version gating `sdk_version_*` (3): per-package
#    language-version feature gating, not an M2 feature.
#  - doc-comment directives & bidi checks (15): doc_directive_*,
#    doc_import_*, uri_does_not_exist_in_doc_import,
#    ambiguous_comment_reference, text_direction_code_point_in_comment,
#    text_direction_code_point_in_literal: doc-comment validation and
#    bidi comment/literal checks are outside the M2 feature set.
#  - pubspec / plugin / analysis-options / lint-management tooling
#    (56 names): asset_*, workspace_*, path_*, removed_lint(_use),
#    replaced_lint(_use), unsupported_chrome_os_* prefixes plus
#    analysis_option_deprecated, analysis_options_deprecated_plugins,
#    camera_permissions_incompatible, dependencies_field_not_map,
#    duplicate_ignore, duplicate_rule, exclude_invalid_glob,
#    flutter_field_not_map, include_file_not_found, included_file_warning,
#    incompatible_lint, incompatible_plugin_source, invalid_dependency,
#    invalid_language_version_override (considered: the M1 gate passed
#    without it and it is not an M2 feature), invalid_option,
#    invalid_platforms_field, invalid_section_format, missing_dependency,
#    missing_name, multiple_combinators, multiple_plugins, name_not_string,
#    no_touchscreen_feature, non_resizable_activity,
#    permission_implies_unsupported_hardware, platform_value_disallowed,
#    recursive_include_file, setting_orientation_on_activity, undefined_lint
#    (M1 precedent: analysis-options code, not a Dart-language diagnostic),
#    unignorable_ignore, unknown_platform, unnecessary_dev_dependency,
#    unrecognized_error_code, unsupported_option, unsupported_value,
#    invalid_widget_preview_application, invalid_widget_preview_private_argument:
#    analyzer's tooling validation surface, which dartq does not implement.
#  - meta-annotation members-use diagnostics (33): @Deprecated/@internal/
#    @protected/@visibleFor*/@mustBeOverridden/@mustCallSuper/@required/
#    @factoryMethod/@redeclare/@doNotStore/@Target-driven families
#    (assignment_of_do_not_store, experimental_member_use,
#    invalid_annotation_target, invalid_await_not_required_annotation,
#    invalid_deprecated_*_annotation, invalid_export_of_internal_element(_indirectly),
#    invalid_factory_method_decl/impl, invalid_internal_annotation,
#    invalid_literal_annotation, invalid_non_virtual_annotation,
#    invalid_override_of_non_virtual_member, invalid_reopen_annotation,
#    invalid_use_of_*, invalid_visibility_annotation,
#    invalid_visible_outside_template_annotation,
#    missing_override_of_must_be_overridden, missing_required_param,
#    must_be_immutable, must_call_super, redeclare_on_non_redeclaring_member,
#    return_of_do_not_store): require package:meta annotation semantics,
#    outside the M2 feature set.
#  - async error-handler special cases (5):
#    argument_type_not_assignable_to_error_handler,
#    body_might_complete_normally_catch_error,
#    invalid_return_type_for_catch_error, invalid_return_type_for_then,
#    unawaited_return_in_try_block: Future.then/catchError-specific
#    checks, not in the M2 worklines.
#  - not tied to an M2 feature (4): non_const_argument_for_const_parameter
#    and tearoff_with_must_be_const_parameter (experimental
#    const-parameters feature, not in the M2 Feature enumeration),
#    unnecessary_final, unnecessary_set_literal (BestPractices style
#    checks with no M2 feature).
